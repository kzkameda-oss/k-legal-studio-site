## こんなお悩みはありませんか

- 500万円以上の工事を受注したいが、許可の要件を満たせるか分からない
- 元請から「許可を取ってほしい」と言われている
- 更新の期限が近いが、毎年の決算変更届を出していない
- 経営業務の管理責任者や専任技術者が退職・交代する
- 一般建設業から特定建設業へ切り替えたい、業種を追加したい

建設業許可は取得して終わりではなく、**毎事業年度の決算変更届**、役員・技術者の変更届、5年ごとの更新と、継続的な手続きが必要です。当事務所では取得から維持までを一貫してお引き受けし、期限管理も含めてサポートします。

## 対応業務

| 手続き | 内容 |
|---|---|
| 新規許可申請 | 知事許可（奈良・京都・大阪など）／大臣許可、一般／特定 |
| 更新申請 | 5年ごとの許可更新。有効期間満了の30日前までに申請 |
| 業種追加 | 解体工事業・とび土工など、業種の追加 |
| 般・特新規 | 一般建設業から特定建設業への切替 |
| 変更届 | 経営業務の管理責任者・専任技術者・役員・商号・所在地・資本金などの変更 |
| 決算変更届 | 事業年度終了後4か月以内に提出する年次の届出（工事経歴書・財務諸表など） |
| 廃業届 | 業種の一部廃業・全部廃業 |

## 許可の主な要件

建設業許可を受けるには、大きく次の要件を満たす必要があります。要件を満たすかどうかの判断が最も難しいところですので、書類をお預かりして事前に確認します。

1. **経営業務の管理責任者等**：建設業の経営経験（役員・個人事業主など）を有する者が常勤していること
2. **専任技術者**：営業所ごとに、資格または実務経験を有する技術者が専任で在籍していること
3. **財産的基礎**：自己資本500万円以上、または500万円以上の資金調達能力があること（一般建設業の場合）
4. **誠実性・欠格要件**：不正・不誠実な行為がなく、欠格要件に該当しないこと
5. **社会保険への加入**：健康保険・厚生年金・雇用保険の適用事業所であれば加入していること

## ご用意いただく書類の例

- 履歴事項全部証明書（法人の場合）
- 直近の決算書・確定申告書（原則3期分）
- 経営経験・実務経験を証明する資料（過去の契約書・請求書・確認済証など）
- 技術者の資格証・卒業証明書
- 社会保険の加入を確認できる書類
- 営業所の写真・賃貸借契約書

※ 申請先や状況により必要書類は異なります。初回相談時に一覧をお渡しします。

## 期間の目安

書類が揃ってから申請までおよそ2〜4週間、申請から許可通知までは知事許可で1か月前後（自治体により異なります）。経験の証明資料の収集に時間がかかるケースが多いため、お早めのご相談をおすすめします。

## 経営事項審査・入札参加資格もあわせて

公共工事の受注をお考えの場合は、決算変更届に続けて[経営事項審査](/services/keishin/)と入札参加資格申請が必要です。決算変更届の段階から経審を見据えた工事経歴書の作成を行います。
