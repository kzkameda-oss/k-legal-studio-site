## 決算変更届とは

建設業許可を受けた会社・個人事業主は、**毎事業年度が終わってから4か月以内**に、その年度の工事の実績と決算の内容を許可行政庁へ届け出なければなりません（建設業法第11条第2項）。これが決算変更届です。

呼び名は申請先によって異なり、奈良県では「決算変更届」、京都府では「決算報告」と呼ばれています。「事業年度終了届」「決算届」と呼ばれることもありますが、同じ届出です。

| 決算月 | 提出期限 |
|---|---|
| 3月末決算 | 7月末まで |
| 6月末決算 | 10月末まで |
| 9月末決算 | 翌年1月末まで |
| 12月末決算 | 翌年4月末まで |

許可を取ったあと、5年ごとの更新までの間に毎年出す届出です。経営事項審査を受けない会社も、工事の実績がなかった年も、提出が必要です。

## 出していないと困ること

- **許可の更新ができません。** 奈良県の手引きには、更新申請には毎年の決算変更届を提出していることが必要と明記されています。京都府でも、更新時の書類の省略や財産的基礎の確認は、決算報告が提出済みであることを前提にしています。
- **経営事項審査が受けられません。** 経審は、その年度の決算変更届を提出したうえで申請します。
- **罰則の定めがあります。** 届出をしない場合や虚偽の記載をした場合について、建設業法は6か月以下の拘禁刑または100万円以下の罰金を定めています（同法第50条）。

更新の直前になって5年分が未提出だと分かると、決算書や工事の資料を5期分さかのぼって集めることになり、更新の期限に間に合わせるのが難しくなります。毎年、決算が確定した時点で出しておくのが確実です。

## 提出する書類

| 書類 | 内容 |
|---|---|
| 変更届出書 | 届出の表紙にあたる書類 |
| 工事経歴書（様式第2号） | その年度に完成した主な工事と、未成工事を業種ごとに記載 |
| 直前3年の各事業年度における工事施工金額（様式第3号） | 業種別・元請下請別の完成工事高の推移 |
| 財務諸表 | 貸借対照表・損益計算書・完成工事原価報告書・株主資本等変動計算書・注記表（個人は貸借対照表・損益計算書）。建設業法の様式で作成 |
| 事業報告書 | 株式会社のみ |
| 附属明細表 | 資本金1億円超または負債200億円以上の株式会社のみ |
| 事業税の納税証明書 | 知事許可の場合。大臣許可は法人税（個人は所得税） |
| 変更があった年だけ出すもの | 使用人数、令3条の使用人の一覧表、健康保険等の加入状況（従業員数の変更）、定款 |

税理士が作成した決算書は、そのままでは提出できません。勘定科目を建設業法の様式に合わせて組み替え、完成工事高と兼業売上高、完成工事原価を分けて作り直します。

## 奈良県と京都府の違い

| | 奈良県知事許可 | 京都府知事許可 |
|---|---|---|
| 呼び名 | 決算変更届 | 決算報告 |
| 提出先 | 管轄の土木事務所（奈良市・天理市・山添村は奈良土木事務所） | 主たる営業所を所管する土木事務所（木津川市・精華町などは山城南土木事務所） |
| 提出部数 | 2部 | 3部 |
| 届出書の様式 | 国の様式（変更届出書）と県の表紙 | 府独自の様式（変更届出書（決算報告）） |
| 電子申請 | — | 国の電子申請システム（JCIP）でも届出可 |

## 経審を受けるかどうかで、工事経歴書の書き方が変わります

工事経歴書は、経営事項審査を受ける会社と受けない会社で記載のルールが異なります。

- **経審を受ける場合**：元請工事の完成工事高の7割を超えるところまで金額の大きい順に記載し、続けて全体の7割を超えるところまで記載します（軽微な工事は10件まで）。奈良県の記載例では、消費税の課税事業者は税抜きの金額で作成します。
- **経審を受けない場合**：主な完成工事を金額の大きい順に10件程度記載します。

経審を受ける会社は、決算変更届の工事経歴書と完成工事高が、そのまま経審の審査の基礎になります。会社の工事台帳が「受注した順」「請求した順」で作られている場合は、**その年度に完成した工事**を拾い直し、業種ごとに分けるところから整えます。

公共工事の受注をお考えの方は、[経営事項審査・入札参加資格](/services/keishin/)のページもご覧ください。

## ご用意いただくもの

- 決算書一式（貸借対照表・損益計算書・株主資本等変動計算書・注記表・勘定科目内訳書）
- その年度の工事の一覧（工事名・注文者・元請下請の別・請負金額・着工と完成の年月が分かるもの）
- 事業税の納税証明書（委任状をいただければ当事務所で取得することもできます）
- 期中の変更の有無（役員・営業所・技術者・資本金・従業員数など）

工事経歴書・工事施工金額・財務諸表の組替えは、当事務所で作成します。

## ご依頼の流れ

1. 決算が確定したら、決算書と工事の一覧をお預かりします
2. 財務諸表を建設業法の様式に組み替え、工事経歴書などを作成します
3. 内容をご確認いただき、土木事務所へ提出します
4. 受付印のある控え（副本）をお渡しします。更新や経審のときに必要になりますので、年度ごとに保管してください

翌年以降は、決算月に合わせて当事務所からご案内します。

## 何年分も出していないとき

未提出の年度があっても、各年度の決算書と工事の資料があれば、さかのぼって作成・提出できます。更新の期限まで時間がないときは、先に必要な資料の一覧をお渡しして、そろったものから順に進めます。

許可の更新・業種追加については[建設業許可](/services/kensetsu/)のページをご覧ください。
